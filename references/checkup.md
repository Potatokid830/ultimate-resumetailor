# 简历体检模式：完整步骤和报告格式

SKILL.md「简历体检模式」的展开。文中"第 X 节"都指 SKILL.md 里的章节。主文件里的底线照样适用：不需要档案、不改写、不出新简历、不为了体检让用户装东西、报告里不写联系方式。

## 步骤

1. 拿到简历（docx、pdf、图片或直接粘贴的文字都行）和 JD。没有 JD 就按用户说的目标方向审，并说明没有 JD 时算不了关键词覆盖率。
2. 有 Python 时顺带跑机筛自检：有 docx 就跑 `python <skill>/scripts/ats_check.py 简历.docx [简历.pdf] [--jd jd.txt] --external`（`--external`：不读 profile，不拿你的档案去查别人的简历，板块认不出只给 ⚠️）；只有 PDF 或图片时，自己按 `ats_check.py` 的标准查（板块标题、联系方式、表格和文本框、字号、页数、口语和第一人称、AI/Al 这类拼写）。没有 Python 也能体检，**不要为了体检让用户装东西**。
3. 按第 0 节第 1 步做资格核查，只用简历上看得到的信息，看不出来的列成问题。
4. 按第 1.6 节**逐句拆解核查**，尽量交给独立审稿的子代理做。
5. 出一份**一页体检报告**（格式见下），在对话里给出，并存成 `<简历文件名>_体检.md`。

## 体检报告格式

**体检报告格式**（适合截图，控制在一屏到一页）：
- **总评**：一句话判断"按现在这版能不能拿到面试"，加上最该先改的 3 件事。
- **数字概览**（只放真实统计出来的数，不凑数）：经历要点 X 条，拆出主张 Y 个，其中 ✅ A 个 / ⚠️ B 个 / ❌ C 个；出现最多的夸大类型；JD 关键词覆盖 a/b（必须项 c/d）；机筛问题 ❌ m 个、⚠️ n 个。
- **逐条明细**（按风险从高到低）：原句 → 拆出的主张和结论 → 面试官会怎么追问 → 建议改法（只往如实的方向改，不加没有依据的内容）。
- **关键词缺口**：漏掉的 JD 必须项和加分项，哪些可以按第 2 节"先写后学"补上。
- **下一步**：想按这个 JD 重写，就进入完整流程；这次体检里用户确认过的事实直接作为素材库初稿，不用再从头讲一遍。

体检结束时问用户一句：要不要把这次确认过的事实存成档案初稿（`profile.json` 和 `materials.md`），以后就不用再讲一遍。

报告里**不写用户的电话、邮箱、住址**。用户说要截图分享时，主动提议把公司名、学校名换成"某券商""某 985 高校"这类说法。
